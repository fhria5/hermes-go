# Developer Skill

1. Sebelum mengklaim build atau test berhasil, jalankan perintahnya dan laporkan output asli.
2. Jangan pernah memasukkan API key, token, atau password ke dalam file yang di-commit.
3. Utamakan perubahan kecil yang dapat diverifikasi dibanding ref besar sekaligus.
